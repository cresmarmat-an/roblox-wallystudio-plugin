# [Plugin] Wally Studio - Install and update Wally packages directly in Studio

Hey everyone!

I'm sharing **Wally Studio**, a plugin I made to install and update Wally packages directly inside Roblox Studio. I wanted an easier way to use packages without opening VS Code, running the Wally CLI, or setting up Rojo.

https://github.com/user-attachments/assets/b333bc57-47ba-4844-b0d5-03341934d08d

The source code is available on GitHub, and I'm sharing it here in case it's useful to you too.

## What it can do

- Search the Wally registry and choose which package version to install.
- Install dependencies and manage shared, server, and development packages.
- Check for updates, update installed packages, and remove packages you no longer need.
- Import and export `wally.toml` manifest text.
- Use Studio's light or dark theme.

## Getting started

1. Install [Wally Studio from the Creator Store](https://create.roblox.com/store/asset/137601836136163/Wally-Studio).
2. Open Roblox Studio and click **Wally Studio** in the **Plugins** tab.
3. Search for a package, choose a version, and install it.
